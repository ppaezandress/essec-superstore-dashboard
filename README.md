# Superstore dashboard - AI & Business Decisions (ESSEC)

Vibe coding challenge, team 8 (store 8: San Diego). Built with Claude Code.

Run locally: `pip install -r requirements.txt` then `streamlit run app.py`.

- `app.py` - the app (phases 1-5)
- `fase1_eda.py` - phase 1 exploratory analysis as a standalone script
- `external_data.py` - phase 5 APIs (datausa.io, open-meteo.com, census.gov) with an offline cache in `external_cache/`
- `promo_engine.py` - phase 4 promotion engine provided by the course
